# 🌟 Site com Carrossel de Imagens com jQuery

Este é um site simples com  imagens responsivo, desenvolvido com HTML, CSS, JavaScript e **jQuery**. O projeto tem como objetivo praticar manipulação de elementos e eventos na DOM de forma dinâmica e interativa.

🔗 **[Veja o projeto funcionando aqui](https://site-de-imagens-c-jquery.vercel.app)**

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- jQuery
